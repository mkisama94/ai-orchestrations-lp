## 3. 受電容量、IT負荷、小規模拠点

| 用語 | 意味 | 掲載上の取り扱い |
|---|---|---|
| 公表供給可能量 | 電力設備について公表された供給側の容量情報 | 個別顧客の確保済み容量と区別 |
| 施設全体の受電容量・契約電力 | IT機器と冷却・電源等を含む施設側の必要電力・契約条件 | 技術検討と契約で具体化。平均負荷だけで決めない |
| IT負荷 | サーバー・GPU等のIT機器が使用する電力 | 電力設備の公表値と同一にしない |
| 一棟／単一敷地／分散拠点 | 建物単位／敷地単位／複数立地という異なる構成 | どの単位で50MWを目指すかを相談時に確認 |

高圧・特別高圧の説明には、[北陸電力送配電・系統アクセスルール（高圧・低圧）](https://www.rikuden.co.jp/nw_rule/attach/keitoukouteiatsu.pdf) の第14条、表14-2を使用する。2026年8月1日版を2026年9月28日に確認。

| 需要設備の契約電力 | 標準供給電圧 |
|---|---:|
| 2,000kW未満 | 6.6kV |
| 2,000kW以上、10,000kW未満 | 22kV |

個別事情による検討規定もあるため、「1,990kWと呼べば必ず6.6kVで接続可能」とはしない。特にIT負荷1,990kWでは、冷却・電源損失等を含めた施設の契約電力が2,000kW未満に収まるとは限らない。小規模化による実工期は、系統・アクセス工事・機器調達等を踏まえて別途確認する。

## 4. 地震比較の対象と条件

- 防災科学技術研究所J-SHISの2024年基準（NIED作成版）、平均ケース（AVR）、全ての地震（TTL_MTTL）、250mメッシュ。
- データ取得日は2026年9月28日。確率の評価起点は2024年1月1日。取得日からの30年確率ではない。
- 2020年版モデルの確率基準日を更新したデータであり、2025年の日本海中南部の海域活断層評価等を反映して全国を再計算したものではない。
- 町名・丁目を国土地理院の住所検索にかけた代表点を使用。具体的なDC敷地、工業団地の中心、分譲中用地を保証しない。
- 22地点には能登の工業地区等、全国のDC立地・開発地域、名古屋都心の参考点を含む。網羅的な全国候補地リストではない。
- 周辺の幅は、代表点から東西・南北約500m間隔の3×3点で取得した値の最小〜最大。信頼区間でも周辺全メッシュの極値でもない。
- 198照会点中194点で有効データを取得。堺は8点、福岡は6点、他は9点。4点のNoDataは欠測として扱う。
- 既存の調査では、22代表点の主要な確率・速度をAPIと個別カルテで照合済み。実装用JSONはその取得データから生成し、丸め前の値・地点・出典・周辺データを保持する。

参照：[2024年基準の公表説明](https://www.j-shis.bosai.go.jp/news-20240719)、[カルテの見方](https://www.j-shis.bosai.go.jp/karte-manual)、[APIの項目定義](https://www.j-shis.bosai.go.jp/api-pshm-meshinfo)、[モデル変更履歴](https://www.j-shis.bosai.go.jp/map/JSHIS2/data/DOC/etc/pshm_condition_change_history.pdf)。

### 表の項目と投資家・需要家の読み方

| 項目 | 意味・単位 | 数値から分かること | 次に確認すること |
|---|---|---|---|
| 地域・代表地点 | 町名代表点を含む250mメッシュ | どこの条件を比較したか | 実際の敷地座標、地盤・造成履歴。変電所の位置と混同しない |
| 30年・震度6弱以上 | 評価起点から30年間に、その地点が6弱以上の揺れを受ける確率（%） | 同一モデル内の揺れの受けやすさ | 建物・設備の設計、地盤、最新の地震知見 |
| 30年・震度6強以上 | より強い揺れの閾値についての確率（%） | 強い地震動側の条件 | 免震・耐震仕様、設備固定、配管・接続部等。6弱以上の確率に足さない |
| 周辺の6弱以上の幅 | 周辺9点等の最小〜最大（%） | 近い場所でも値が変わる程度 | 用地の細かな位置。敷地全体の上下限とはみなさない |
| 50年超過確率10%の地表PGV | その超過確率に対応する最大地動速度（cm/s）。約475年の再現期間に相当 | 共通の発生頻度条件で想定される地震動の大きさ | 構造・設備の応答評価。変位・損失率・設計保証ではない |
| 地盤増幅率 | 工学的基盤（Vs=400m/s）から地表までの最大速度の増幅倍率 | 地盤による速度増幅の目安 | ボーリング、盛土、液状化、支持地盤。表のPGVに再度掛けない |

PGVや地震動確率だけから、DCの損害額、停止時間、保険料、PMLを算出しない。「2%だから残り98%は無事故」「PGVが半分だからPMLも半分」とは読めない。

### PMLと事業継続を分ける

PMLは、定められた地震動・建物等の条件における物的損害を、再調達価格に対する割合などで表す指標。評価機関の定義・対象範囲を合わせて比較する。例えば東京海上ディーアールは、50年間の超過確率10%の地震動に対し、損害側の90%非超過水準を用いる。[同社の評価説明](https://www.tokio-dr.jp/service/due_dili/eq_pml/)。

個別評価では建物だけか、受変電・冷却・ラック・GPU等を含むか、津波・液状化等をどう扱うか、評価基準日と再調達価格を明記する。今回の比較表はPML未評価。

投資家は物的損害・修復費・保険と事業中断損失を、需要家は電源・冷却・通信・アクセス・燃料補給・復旧条件を別途確認する。PMLが同じでも停止時間や収益への影響は同じとは限らない。

主な要件は投資5,000万円以上、常時雇用者数の純増5人以上。通常の県限度額は5億円。特認は投資100億円以上、市町が同等助成を行う場合等を条件とし、県10億円、市町分合わせて20億円。県補助額は市町助成額を超えない。旧5村は河内・吉野谷・鳥越・白峰・尾口。

公表計算式は投資額×補助率に純増常時雇用者数×50万円を加えるもの。実際の対象経費の認定と上限を踏まえるため、設備投資総額に率を掛けただけの金額を受給見込額として表示しない。増設は別条件。対象経費・申請時期・併用の扱いは県・市町に個別確認する。

## 6. 公開前の更新ルール

電力・補助制度は公開前に一次資料の変更を確認する。地震データはモデル版と取得日を別々に管理し、新しい版へ更新する際は全地点を同条件で取り直す。地点を変更した場合は変更前後の住所・座標・選定理由を残す。

自社の案件状況は公表情報と別に管理する。供給契約、用地権利、需要契約、第三者評価などの追加事実が得られた場合は、公開可能な範囲と確認日を記録してLPへ反映する。
